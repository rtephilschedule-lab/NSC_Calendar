Install Member Hub on Your Phone

You can save this page directly to your home screen so it functions like a regular app for quick, one-tap access:

Android (Chrome / Samsung Internet):

  1. Tap the menu icon (three dots in the top-right corner).
  2. Select Install and create shortcut (or Add to Home screen).
  3. Confirm by tapping Install or Add.

iPhone / iPad (Safari):

  1. Tap the Share button (the square with an arrow pointing upward at the bottom of the screen).
  2. Scroll down and tap Add to Home Screen.
  3. Tap Add in the top-right corner.
    (Note: If using Chrome or Firefox on an iPhone, you may need to open the page in Safari first.)
